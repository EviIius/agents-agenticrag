# Evidence contract checkpoint — 9 October 2026

Jake authorized this isolated checkpoint after the failed reliability review.
The attachment warning correction is a separate, reversible UI change. The
existing 25% / 1,024–8,192 response reservation remains an estimate, never a
new provider sampling parameter. No Research restart, download, dependency,
runtime update, default switch or reliability deployment is part of this work.

## Frozen pilot

- Keep the original 20 everyday, 25 Web and 34 Library cases, their saved
  evidence, required facts, graders and release thresholds. One full pilot per
  installed profile, ordered baseline then candidate. Do not retry a failed
  profile or run three repeats unless its first full pilot qualifies.
- Ordinary chat retains the stable production context builder and answer
  contract. The isolated Web planner retains the evaluated v7 module; Search
  selection adds the generic table priority prototype in the actual pipeline.
- Source snapshots retain title, URL, publication and retrieval timestamps,
  page/section information, complete selected paragraphs and table fields.
  Units identify their original source/passage, table header, cells and caption.
  Pronouns retain preceding subject context; unresolved subjects and ambiguous
  columns are rejected. Multiple IDs per source can be selected.
- The existing answer call returns selection JSON only. No judge, retry,
  router, new tool or additional inference call. IDs, source ownership,
  duplicates, response shape, completion status and per-source quotation limits
  are checked before host-owned literal text is emitted. Rejected and empty
  selections explicitly decline; partial selections state their limitation.
- Preserve the earlier 25-word per-source quotation cap. This conservative cap
  may make complete table answers impossible. That is a contract/coverage
  failure to report, not permission to trim required facts or call it a pass.
- Safe escaping prevents source HTML, links and reference markers from creating
  active answer content. Sources remain the pipeline's original snapshots.
- Raw selection JSON and reasoning are buffered inside the isolated adapter;
  they never become persisted assistant text. Cancellation/provider failure
  cannot release a partial selection. This changes validated-answer latency
  and fluency, which must be measured and reviewed before product integration.

## Review and stop

Record full automated outcomes, effective module hashes, selected units,
raw inference and rendered text. Manually inspect every grounded turn for
identity, property/value binding, dates, negation, relevance, injection and
requested coverage. Separately flag answer-format failures. Retain absent
currency, personal identity and complete-list cases without substituting new
evidence. Schema/provenance success is never reported as verified truth.

New synthetic tests cover captions, repeated headers, infobox ambiguity,
empty cells, signed decimals, time limits, unsupported fields and invalid IDs.
These are controls, not a replacement for full benchmark or live-provider gates.
Any missed factual, semantic, injection, coverage or performance gate keeps the
contract isolated. Product integration, SSE notices/export design and deployment
await the H4 review and the existing regression and live-provider requirements.
