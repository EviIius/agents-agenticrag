## Frozen design

v15 maps each selected owned unit ID to one named bundle. For a row, bundles
contain required identity/scope columns plus one or two additional original
columns, or the entire original row. This is polynomial, not exhaustive powerset
enumeration; requests requiring other combinations may remain incomplete. There
are no topic-specific choices. Each proposed bundle is admitted by the same
unchanged v13 host validator used for final cumulative checks. Unrenderable
standalone prose is omitted from selectable input without cutting its context
or altering its stored source snapshot. Payloads expose standalone costs.

The native grammar permits only admitted bundle names. It does not encode every
global coverage relationship or aggregate budget; those remain host checks.
Admission does not establish relevance, requested completeness or semantic truth.
