# Appearance handoff

The established themes, accents, reading fonts and spacing remain the visual reference. Their complete definitions live in `src/agenticrag/ui/tokens.css`; the bundled font files and licenses live in `src/agenticrag/ui/fonts`.

The current interaction specification is `docs/architecture.md`. Use one chat composer, compact Web access, model selection, Sources and Settings. On mobile, retain 44px touch targets and keep the composer outside the conversation scroll area. Citation dialogs must fit inside the viewport. Tables may scroll horizontally inside a message.

Earlier interaction mockups and duplicate assets have been removed. The original design handoff is recoverable in the external pre-update backup.
