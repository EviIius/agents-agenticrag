# Proposed next step: structured source mechanics

12 October 2026. **Proposal only; no new inference, product change or deployment
is authorized by this document.** The bounded table comparison has stopped.

## Why this is the next useful change

There is a measured passage-admission defect, but both fresh native plans bypass
it through the existing qualifying-condition path. Their matching complete lists
therefore cannot demonstrate that the new selector improved answers. One extra
unsupported relationship still fails the candidate. More broad prompt wording
would not repair lost headers or absent evidence.

## One offline engineering scope

1. Preserve original structured table headers, participants, roles, units,
   empty cells and literal values during extraction/chunking. Reproduce the
   already-audited original role-table loss and missing repeated headers. Use
   the existing stack; no added dependency or inferred field value.
2. Exercise the exact retained omission branch with its original recorded plan,
   source bytes and context ratio. Keep the isolated table selector and its
   negative tests; do not claim the successful qualifying-condition path tests
   the fallback repair.
3. Record requested facets that are missing from actually supplied sources.
   Diagnostics must distinguish unfetched evidence, unreadable structure and
   ranked-out passages. Do not treat a menu name or memory answer as a supplied
   entity/property assertion.
4. Preserve the original benchmark, thresholds and scores. Any later refreshed
   coverage-checked corpus is separate, with identical evidence for both arms;
   it cannot erase original failures or qualify from easier cases.
5. Stop with measured mechanical results and one concrete native question/order
   for review. No prompt change, new model/runtime, extra production call,
   broad inference campaign or release follows from an offline pass.

## Practical product limit

Source cards / “What the model saw” already expose the supplied evidence. Use
that transparency and keep factual generated outputs reviewable. Exact source
tables are useful evidence; a plausible cited paraphrase is not a verified fact.
Unattended factual workflows remain unqualified. Image release and W1 retain
their existing reviewed sequence and gates; Research remains shelved.
