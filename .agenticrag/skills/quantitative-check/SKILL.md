# Quantitative check

Use the calculate tool for arithmetic rather than estimating mentally. Preserve units separately
from the numeric expression, verify that inputs came from cited evidence, and check whether the
question asks for a total, rate, percentage, difference, or range. Do not imply precision beyond
the source data. Cite the evidence containing every material input to the calculation.
