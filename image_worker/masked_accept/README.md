# One-slot overlap acceptance check

Scope: `docs/PHOTO-EDITING-PE6-ACCEPTANCE-PLAN.md`. Earlier budgets stay closed.
Exactly one FLUX head generation is allowed, using the already installed recipe.
Qwen is not a declared case. The controller derives from the PE4 paired control,
with a one-slot approval and no second-engine continuation. Native calls,
resource verification, output binding, shared lease and owned reaping are unchanged.

Prepare the reviewed private selection/feature mask first. The old-native
recomposition is explicitly diagnostic and retains its original context transform;
it is not a new generation. `prepare.py --root <fresh-private-root>
--preparation <reviewed-private-inputs>` verifies the prior scope and declared
retained glove hashes, checks CPU masks, verifies FLUX files and freezes inputs.

Run `run.py flux --root <private-root>` under the server interpreter, once.
`audit.py finish --root <private-root>` runs under the isolated image interpreter
and uses direct RGB differences without importing the compositor. It verifies
the new export, protected visible facial features and all unselected pixels, and
combines the predeclared retained FLUX glove outputs. No hidden fresh glove edit,
post-result mask change, retries, helper model or native continuation.

Real instructions, photographs, coordinates, native images, masks and review
media remain private. Only sanitized measurements, synthetic tests and source
hashes enter Git. A failed quality result shelves precision editing.
