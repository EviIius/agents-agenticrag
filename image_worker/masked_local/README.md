# Focused-region trial — isolated only

Scope: `docs/PHOTO-EDITING-PE5-LOCAL-TRIAL-PLAN.md`, six new calls maximum.
This is a new quality strategy, not an integration or a repeated old allowance.

`prepare.py --root <new-private-root> --instructions <private-json>` partitions
the retained reviewed selection, proves its exact union/disjointness/face
exclusion, verifies installed model content, and freezes all requests and source.
The private instruction object has `hat`, `front`, `rear` text fields.
Instructions, original photos, mask coordinates and output media never enter Git.

`scope.py <hat|front|rear> <flux|qwen> --root <private-root>` runs under the server
interpreter. It enforces the six-case order, immutable scope inputs and prior
technical passes/output-bound manual reviews, then delegates to the unchanged
PE4 paired controller/launcher. Each region has its own append-only two-slot
ledger. Native workers/settings, process reaping and host guards are reused byte
for byte. A technical failure stops all subsequent cases. Visual failures remain
reviewable and do not cancel the declared quality comparison.

All edits use the same original independently. `cpu.py finish --root <root>`
runs under the isolated image interpreter, audits direct RGB differences and
combines only the three disjoint selected areas. It changes no native output.
Regional raw/composite/export files and full combined results are retained.

One run per region is a diagnostic of focused editing, not a consistency claim.
Keep original one-shot results and all unsuccessful outputs for comparison.
