# Product context

Chat & Web focuses on normal conversation completion and dependable public web search across the configured models. The user selects a model and controls Web Off, Ask or On. The host searches, reads pages and supplies numbered excerpts in a fixed sequence. Answers stream as they are written.

Keep chat history, projects, model configuration, inspectable immutable sources and Save to library. Show page failures explicitly. Use no private corpus passages or previous assistant reports as web evidence. A small set of sources and linked citations is not a claim of exhaustive coverage or verified truth.

Current scope and implementation are described in README.md and docs/architecture.md.
